# R2RETRO v0.5.13 · Instalación directa de actualizaciones (sin BGFT)

**Versión experimental para PS4 homebrew.** Incluye N64, NES, SNES, GB, GBC y GBA. No incluye ROMs comerciales ni BIOS externas.

## Novedades

- **Autoactualización sin BGFT.** El registro en el servicio de descargas devolvía `0x80990088` («contenido ya existe») con cualquier combinación de parámetros. El instalador ahora usa el método directo de flatz: `sceAppInstUtilAppPrepareOverwritePkg` + `sceAppInstUtilAppInstallPkg`, que mueve el PKG a `/user/app/<title id>/app.pkg` sin copia intermedia de BGFT.

## Instalación

[Descargar PKG](https://github.com/R2two/R2RETRO/releases/download/v0.5.13/R2RETRO-v0.5.13-installer-fix.pkg) · [SHA-256](https://github.com/R2two/R2RETRO/releases/download/v0.5.13/R2RETRO-v0.5.13-installer-fix.pkg.sha256)

Instala manualmente por USB o FTP + Package Installer HDD de GoldHEN, sobre la versión anterior y sin desinstalar. Se conservan Title ID `RNTD00064`, Content ID `IV0001-RNTD00064_00-R2N64APP00000001` y datos `/data/R2N64`.
