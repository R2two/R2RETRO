# R2RETRO v0.5.9 · Corrección del instalador de actualizaciones

**Versión experimental para PS4 homebrew.** Incluye N64, NES, SNES, GB, GBC y GBA. No incluye ROMs comerciales ni BIOS externas.

## Novedades

- **Autoactualización corregida.** Al instalar una versión superior desde *Ajustes → Actualizaciones*, el instalador registraba la tarea con `FORCE_UPDATE`, lo que BGFT rechazaba con «contenido ya existe» (`0x80990088`) y dejaba el PKG conservado sin desinstalar. Ahora se registra como actualización normal (`ORBIS_BGFT_TASK_OPT_NONE`), que BGFT reconoce por la versión superior del SFO.
- Se inicializan los campos de cadena de BGFT (`contentExUrl`, `skuId`, `releaseDate`) que quedaban en `NULL`.
- El conflicto `0x80990088`/`0x80990015` muestra un mensaje claro: revisa Notificaciones → Descargas o cancela una actualización previa.

## Instalación

[Descargar PKG](https://github.com/R2two/R2RETRO/releases/download/v0.5.9/R2RETRO-v0.5.9-installer-fix.pkg) · [SHA-256](https://github.com/R2two/R2RETRO/releases/download/v0.5.9/R2RETRO-v0.5.9-installer-fix.pkg.sha256)

Instala manualmente por USB o FTP + Package Installer HDD de GoldHEN, sobre la versión anterior y sin desinstalar. Se conservan Title ID `RNTD00064`, Content ID `IV0001-RNTD00064_00-R2N64APP00000001` y datos `/data/R2N64`.
