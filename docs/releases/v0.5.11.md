# R2RETRO v0.5.11 · Corrección real del autoinstalador (BGFT id vacío)

**Versión experimental para PS4 homebrew.** Incluye N64, NES, SNES, GB, GBC y GBA. No incluye ROMs comerciales ni BIOS externas.

## Novedades

- **Autoactualización corregida (causa raíz).** El registro BGFT pasaba el Content ID instalado en el campo `id`, y BGFT respondía «contenido ya existe» (`0x80990088`). Siguiendo el método de flatz para instalar PKG desde HDD interno, ahora se registra con `id=""` (vacío) y la opción `DISABLE_CDN_QUERY_PARAM`. Ya no choca con el R2RETRO instalado al subir de versión.
- Se conservan las mejoras previas del instalador: campos de cadena BGFT inicializados (sin `NULL`) y mensaje claro para conflictos de contenido.

## Instalación

[Descargar PKG](https://github.com/R2two/R2RETRO/releases/download/v0.5.11/R2RETRO-v0.5.11-installer-fix.pkg) · [SHA-256](https://github.com/R2two/R2RETRO/releases/download/v0.5.11/R2RETRO-v0.5.11-installer-fix.pkg.sha256)

Instala manualmente por USB o FTP + Package Installer HDD de GoldHEN, sobre la versión anterior y sin desinstalar. Se conservan Title ID `RNTD00064`, Content ID `IV0001-RNTD00064_00-R2N64APP00000001` y datos `/data/R2N64`.
