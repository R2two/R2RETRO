# R2RETRO v0.5.5 · Imagen, guardados y red

**Pre-release experimental para PS4 homebrew.** Incluye seis sistemas: N64, GB, GBC, GBA, NES y SNES. No incluye ROMs comerciales ni BIOS externas.

## Novedades

- Shaders **LCD suave / CRT suave** para GB/GBC/GBA/NES/SNES desde L3+R3 → Shader. Preferencia por consola; desactivados por defecto. Requieren GLES2; ante fallo se conserva la imagen normal.
- **Escribir partida SRAM/RTC** desde pausa, sin cerrar el juego. No sustituye Guardar dentro del juego; se informa si el cartucho no tiene memoria persistente o falla la escritura.
- **Salto GBA** nativo de mGBA: todos los cuadros, uno de cada dos o uno de cada tres. Desactivado inicialmente; reduce fluidez y puede aliviar el dibujo, sin garantía de velocidad completa.
- **Cloudflare DoH fijo** para actualizaciones, información y carátulas de Libretro, conservando TLS y el DNS global de PS4.
- Logos de consola separados en seis texturas pequeñas, con subida comprobada y respaldo de iconos. La corrección del reporte de cuadros blancos todavía necesita confirmación física.
- Biblioteca organizada por consola, nuevo fondo de habitación retro y perfiles N64 automáticos experimentales para las identidades exactas de Mario USA y Zelda OoT USA 1.2.
- Actualizador integrado: consulta, descarga verificada y solicitud de instalación desde Ajustes → Actualizaciones. Incluye mejoras N64 de compatibilidad posteriores a la publicación v0.5.1.

## Instalar o actualizar

[Descargar el PKG](https://github.com/R2two/R2RETRO/releases/download/v0.5.5/R2RETRO-v0.5.5-display-network.pkg) · [SHA-256](https://github.com/R2two/R2RETRO/releases/download/v0.5.5/R2RETRO-v0.5.5-display-network.pkg.sha256)

- Desde versiones sin actualizador: instalación manual por USB.
- Desde v0.5.3/v0.5.4: Ajustes → Actualizaciones → canal experimental → buscar → descargar → instalar y cerrar. En v0.5.4 activa Cloudflare si el DNS del sistema impide la conexión. Si no puedes consultar el canal, instala por USB.
- Se mantienen Title ID `RNTD00064`, Content ID `IV0001-RNTD00064_00-R2N64APP00000001`, datos `/data/R2N64` y USB `R2N64/roms/{n64,gb,gbc,gba,nes,snes}`. No desinstales para actualizar.
- La solicitud de instalación sobre sí misma usa BGFT; la finalización en PS4 física sigue pendiente de comprobación. Instalar el PKG nuevo manualmente no valida esa función.

## Pruebas y límites

- Compilación desktop y PS4 con OpenOrbis/PacBrew existentes; PKG extraído, SFO/identidad, hashes y recursos validados.
- **52/52 grupos CTest aprobados** entre la ejecución completa (51) y la repetición del actualizador (1) tras corregir su fixture de versión futura. No fue un fallo del instalador: se rechazó correctamente una versión igual a la instalada.
- Pruebas originales de GB/GBC/GBA/NES/SNES, SRAM manual, persistencia, frameskip GBA con CPU/input/PCM conservados, shader on/off y preservación del estado SDL/GLES2. Son pruebas Linux/Mesa, no medidas PS4.
- El validador del cliente acepta el manifiesto de esta versión y verifica el PKG real (SHA-256, identidad y SFO).
- **No hay prueba física de v0.5.5 ni mejora de velocidad N64 medida.** N64 no añade frameskip ni Vulkan; shaders nuevos tampoco se aplican a N64. Se mantienen las limitaciones de compatibilidad de chips SNES y estados N64 GPU/HLE.
