## Novedades

- GLideN64 GLES2 con HLE gráfico para tareas reconocidas y respaldo CXD4 real para las restantes.
- Modos seleccionables: Angrylion, GPU + HLE gráfico y GPU + RSP LLE. El inicial sigue siendo Angrylion.
- Contadores de tareas y perfil opcional del intercambio SDL/núcleo en pausa.
- Reloj de tiempo transcurrido específico de PS4; no mide exclusivamente tiempo de ejecución GPU.
- Se conserva el puente audio HLE, la integración de los otros sistemas y la compatibilidad de datos.

La selección gráfica se aplica al abrir la próxima ROM y dura la sesión de la aplicación. Los estados rápidos en la ruta GPU siguen deshabilitados.

## Funciones acumuladas

N64/Mupen64Plus-Next, GB-GBC/SameBoy, GBA/mGBA, NES/FCEUmm y SNES/bsnes-mercury; XMB, USB, guardados, estados según núcleo, capturas, marcos, paletas GB, avance rápido portátil/NES/SNES y fichas/carátulas Libretro con caché.

## Instalación y actualización

Instalar el PKG en una PS4 con entorno homebrew compatible y GoldHEN ya configurado. Firmware/GoldHEN exactos aún no certificados. Mantener `/data/R2N64` y `R2N64/roms` en USB: el cambio de nombre público a R2RETRO no modifica las rutas, Title ID ni identidad de partidas. Respaldar las partidas antes de probar versiones experimentales.

Primera prueba sin ROM comercial: **Acerca de → Prueba Nintendo 64**. Para juegos propios: **Biblioteca → Triángulo → seleccionar → X → X**. [Guía](../USER-GUIDE.md).

## Evidencia y problemas conocidos

- Registros existentes: 49/49 CTest, ASan/UBSan del despachador y 10/10 regresiones focalizadas finales aprobados.
- PKG extraído y validado por el empaquetador; SHA-256 comprobado de nuevo para esta publicación.
- Mario/Zelda: 9.600 VI en frontend y 2.400 VI adicionales para revisar UI. Las ocho comparaciones locales suman 16.800 VI con calentamiento.
- Reducciones locales del tiempo por VI: 37,4 % Mario / 11,9 % Zelda en Linux/Mesa. **No son mejoras demostradas en PS4**. Existen diferencias visuales HLE/LLE.
- El usuario informa rendimiento similar después de v0.5.1; faltan backend efectivo, contadores y perfil físico de esa sesión. El metadato original `ps4_hardware_tested: false` se conserva; los comentarios posteriores no equivalen a validación controlada.
- Sin compatibilidad universal de juegos/chips; estados GPU y ciertos chips SNES limitados. Un mando, sin vibración. Laboratorio 3D desktop fuera del PKG.
